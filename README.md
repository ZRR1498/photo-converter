# photo-zipper

Open-source **Photo Converter** — batch-convert photos (JPEG, HEIC, PNG, …) to a chosen format without modifying originals.

All application code lives in [`main-app/`](main-app/).

```bash
cd main-app
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

See **[main-app/README.md](main-app/README.md)** for full docs: quality policy, tests, PyInstaller builds for Linux / Windows / macOS, and license (MIT).
